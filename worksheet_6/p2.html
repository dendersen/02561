Texture filtering:
magFilter controls filtering when the texture is magnified.
With nearest, the closest texel is sampled, so the image stays sharp but may look blocky. With linear, neighboring texels are blended, making the image smoother but sometimes blurrier.

minFilter controls filtering when the texture is minified.
Using nearest can look pixelated and show aliasing, while linear blends neighboring texels for a smoother result but may still show aliasing.

Mipmapping can be turned on or off.
When it is on, smaller versions of the texture help reduce aliasing when minified. mipmapFilter controls how these versions are sampled: nearest selects one mipmap level, while linear blends between levels for smoother transitions.
